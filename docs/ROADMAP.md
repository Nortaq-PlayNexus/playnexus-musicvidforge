# Roadmap

High-level direction for MusicVidForge. Ordered roughly by priority; dates are
indicative.

## 1.1 — Polishing (next)

- [ ] Rendering queue so you can chain multiple songs/templates.
- [ ] Batch export of one template across many songs.
- [ ] Real-time preview of a template before full render.
- [ ] Native packaging (`pyinstaller` one-click build) with signed installer.

## 1.2 — Content tools

- [ ] Karaoke-style lyric/CAPTION sync overlay.
- [ ] Multi-layered overlays (image + text + effects) with simple keyframes.
- [ ] Loopable seamless music-visual export.

## 1.3 — Platform & ecosystem

- [ ] Official macOS and Linux support (verified CI runs).
- [ ] Direct upload to YouTube/TikTok via `yt-dlp`-style auth flows (opt-in).
- [ ] Plugin API for community templates.

## Always

- [ ] New beat-synced templates (contributions welcome, see CONTRIBUTING).
- [ ] Faster encoders, GPU-accelerated frame generation experiments.

> Got a feature you want? Open an issue or a pull request.
