## [1.0.0] - 2026-08-11

### Added

- Initial public release.
- 8 beat-synced visual templates: Matrix Rain, Beat Pulse, Spectrum Bars,
  Audiogram Wave, Digital Glitch, Beat Fireworks, Photo Zoom, Synthwave Grid.
- Offline beat/BPM detection via NumPy (spectral flux).
- Output up to 4K, 60 FPS; 16:9 / 9:16 / 1:1 aspect ratios.
- Encoders: H.264, H.265, NVIDIA NVENC.
- Overlay filters: vignette, scanlines, beat flash, matrix overlay.
- Custom colours, beat sensitivity, background image and title overlay.
- Original audio muxed into the output as 320k AAC.
- Full documentation suite, test suite and CI/CD workflows.
